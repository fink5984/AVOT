# בדיקות קבלה עם חומרה (ידני)

הבדיקות האוטומטיות מכסות את כל המסלול עם מצלמה מדומה. הבדיקות כאן מחייבות חומרה אמיתית וטרם בוצעו. סמנו ✔ / ✘ ותאריך.

## א. סמארטפון כמצלמת רשת (תוספת §6)
הכנה: חברו את הטלפון כמצלמת רשת (הוראות באתר: הגדרות ← העדפות צילום ← ״חיבור סמארטפון כמצלמת רשת״, כתובת `/settings#phone`).

| # | שלב | תוצאה צפויה | ✔/✘ |
|---|---|---|---|
| 1 | פתחו את AVOT Studio ב-Chrome/Edge (localhost או HTTPS) | נכנס למערכת | |
| 2 | צרו קטלוג חדש, הוסיפו ״נועם אלימלך״ | פריט מספר 1 אוטומטי | |
| 3 | ״צילום״ ← בחירת מצלמה ← מצלמת הטלפון | Live View אמיתי מהטלפון; ברזולוציה בראש המסך | |
| 4 | קטגוריית ״שער״, 3 צילומים בכפתור | 3 תמונות ברצועה, כל אחת עוברת ״נשמר מקומית״ ← ✓ ״נשמר בענן ואומת״ | |
| 5 | ״תמונות פנימיות״, 5 צילומים במקש רווח | 5 תמונות, שיוך נכון | |

## ג. Canon EOS R7 דרך digiCamControl (בלי EDSDK שלנו) — טרם בוצע
הכנה: [digicamcontrol.md](digicamcontrol.md) §7. הבדיקות האוטומטיות הן מול mock בלבד — השאלות שלמטה נענות רק כאן.

| # | שלב | תוצאה צפויה | ✔/✘ |
|---|---|---|---|
| 1 | הדלקת R7 + digiCamControl פועל, שרת Web מופעל | `list cameras` מחזיר את המצלמה; במגש: מצלמה מחוברת. **אם לא — לתעד את גרסת digiCamControl והאם R7 נתמכת** | |
