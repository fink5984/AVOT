# בדיקות קבלה עם חומרה (ידני)

הבדיקות האוטומטיות מכסות את כל המסלול עם מצלמה מדומה. הבדיקות כאן מחייבות חומרה אמיתית וטרם בוצעו. סמנו ✔ / ✘ ותאריך.

## א. סמארטפון כמצלמת רשת (תוספת §6)
הכנה: חברו את הטלפון כמצלמת רשת (הוראות באתר: הגדרות ← העדפות צילום ← ״חיבור סמארטפון כמצלמת רשת״, כתובת `/settings#phone`).

| # | שלב | תוצאה צפויה | ✔/✘ |
|---|---|---|---|
| 1 | פתחו את AVOT Studio ב-Chrome/Edge (localhost או HTTPS) | נכנס למערכת | |
| 2 | צרו קטלוג חדש, הוסיפו ״נועם אלימלך״ | פריט מספר 1 אוטומטי | |
| 3 | ״צילום״ ← בחירת מצלמה ← מצלמת הטלפון | Live View אמיתי מהטלפון; ברזולוציה בראש המסך | |
