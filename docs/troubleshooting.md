# טיפול בתקלות מצלמה וסנכרון

## מצלמת רשת / טלפון
| תסמין | סיבה אפשרית | פתרון |
|---|---|---|
| ״הגישה למצלמה נחסמה״ | הרשאת דפדפן | סמל המנעול בשורת הכתובת ← מצלמה ← אפשר; רענון |
| ״המצלמה תפוסה על ידי תוכנה אחרת״ | Zoom/Teams/אפליקציית מצלמה | סגרו אותן; ״חיבור מחדש״ |
| הטלפון לא מופיע ברשימה | Phone Link / התוכנה לא פועלת | ודאו שהטלפון מוצג כמצלמה ב-Windows (אפליקציית ״מצלמה״); ״סריקה מחדש״ |
| ״דורש חיבור מאובטח״ | האתר נפתח דרך כתובת IP בלי HTTPS | פתחו דרך `localhost` במחשב המקומי או דרך כתובת ה-HTTPS |
| רזולוציה נמוכה | התוכנה המחברת את הטלפון מגבילה ל-720p/1080p | הגדירו רזולוציה גבוהה בתוכנה; הרזולוציה בפועל מוצגת בראש מסך הצילום |
| הצילום נחסם: ״אין מספיק מקום באחסון המקומי של הדפדפן״ | הרבה צילומים ממתינים + דיסק מלא | המתינו לסיום ההעלאה; פנו מקום בכונן C |

## Canon EOS R7 / Capture Agent
| תסמין | פתרון |
|---|---|
| ״Canon EDSDK לא הותקן״ | העתיקו EDSDK.dll + EdsImage.dll ([canon-edsdk.md](canon-edsdk.md)); יציאה והפעלה מחדש של Agent |
| ״לא זוהתה מצלמת Canon״ | כבל USB ישיר (לא מפצל), המצלמה דולקת ובמצב צילום, אין חיבור Wi-Fi פעיל למחשב |
| ״המצלמה בשימוש של תוכנה אחרת״ | סגרו EOS Utility / Lightroom tethering / תוכנות Canon אחרות |
| ״המצלמה לא הצליחה למקד״ | תאורה, מרחק מינימום של העדשה; או כבו ״מיקוד אוטומטי בכל צילום״ ומקדו ידנית |
| הדפדפן לא מוצא את Capture Agent | המגש: האם ״A״ מופיע? פתחו `http://127.0.0.1:47800/v1/hello` בדפדפן. אשרו ״גישה לרשת המקומית״ אם הדפדפן ביקש |
| ״העמדה בשימוש כעת על ידי …״ | משתמש אחר מחובר לעמדה; השליטה משתחררת 30 שניות אחרי שסגר את מסך הצילום |
| ״העמדה בוטלה בשרת״ | מנהל ביטל את העמדה; צימוד מחדש (מגש ← צימוד לשרת) |
| ניתוק USB באמצע | התוכנה מנסה להתחבר מחדש כל 3 שניות. צילומים שכבר ״נשמר מקומית״ לא נפגעים |
| קבצים בתיקייה `_unassigned` | קובץ שהגיע מהמצלמה כשלא היה פריט פעיל, או קובץ חלקי אחרי קריסה. לא נמחק אוטומטית — ייבאו אותו ידנית במסך הספר (לשונית הקטגוריה ← ״ייבוא מהמחשב״, או גרירת הקובץ) לאחר בדיקה |

יומנים: מגש ← ״תיקיית יומנים״ (`%LOCALAPPDATA%\AvotCapture\logs`).

## סנכרון
| תסמין | משמעות ופתרון |
|---|---|
| ״ממתינות להעלאה: N״ לא יורד | אין אינטרנט / השרת לא זמין. הקבצים שמורים מקומית וינסו שוב (backoff עד 5 דק׳) |
| ⚠ ״דורש טיפול״ | 6+ ניסיונות נכשלו או שגיאה קבועה (למשל הפריט נמחק בשרת, או קובץ מקומי פגום). פרטי השגיאה ברחיפה על הצילום; ״ניסיון העלאה חוזר עכשיו״ ברצועה. בדוחות ← תקלות סנכרון |
| ״בדיקת השלמות נכשלה״ | הבתים שהגיעו לשרת שונים מהמקור. השרת מחק את הגרסה הפגומה; ההעלאה תחזור. אם חוזר שוב ושוב — קובץ המקור בדיסק פגום; פנו למנהל |
| פג תוקף התחברות באמצע העלאות | התחברו מחדש; התור ממשיך מאותה נקודה |
| צילומים בדפדפן אחד ונכנסתי מדפדפן אחר | תור הדפדפן שייך לדפדפן שבו צולם. פתחו את האתר שוב באותו דפדפן ובאותו מחשב כדי שיסיים להעלות |
