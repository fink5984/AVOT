# Capture Agent — תוכנת עמדת הצילום

תוכנת Windows (x64, ‏.NET 10) שרצה ממגש המערכת במחשב שאליו מחוברת המצלמה. אחראית על: שליטה במצלמה (Canon EDSDK או סימולטור), שמירת המקור בדיסק **לפני** כל אישור, תור העלאה עמיד, ו-API מקומי ל-127.0.0.1 עבור מסך הצילום.

## התקנה בעמדה
1. הריצו `AvotCaptureAgent-Setup-<ver>.exe` (התקנה למשתמש הנוכחי — ללא הרשאות מנהל; כוללת את ‎.NET runtime).
2. העתיקו את Canon EDSDK לתיקייה `EDSDK` שבתיקיית ההתקנה ([canon-edsdk.md](canon-edsdk.md)).
3. בפעם הראשונה ייפתח חלון ״צימוד לשרת״. באתר: הגדרות ← עמדות צילום ← צימוד עמדה חדשה → העתיקו כתובת וקוד.
4. אופציה: ״הפעלה אוטומטית עם Windows״ (בתפריט המגש ובהתקנה).

## בנייה מהמקור
```powershell
cd apps\capture-agent
dotnet build                                  # Debug
dotnet test                                   # 24 בדיקות
dotnet run --project src\AvotCapture.Agent    # הרצה עם מגש מערכת
.\build-installer.ps1 [-Version 0.2.0]        # tests → publish self-contained → Inno Setup 6
```
`build-installer.ps1` דורש Inno Setup 6 (https://jrsoftware.org/isdl.php). בלעדיו נוצרת רק תיקיית `artifacts\publish`.

## שורת פקודה
```
AvotCaptureAgent.exe [--tray] [--headless] [--data <dir>] [--storage <dir>] [--port <n>] [--camera CANON|SIMULATOR]
AvotCaptureAgent.exe --pair <serverUrl> <code> [name]
```
`--headless` — ללא ממשק (לבדיקות/שירות). `--data` — תיקיית הגדרות/מסד/יומנים חלופית.

## היכן נשמר מה
| מה | מיקום |
|---|---|
| תמונות מקוריות | `%USERPROFILE%\Pictures\AVOT Studio\Catalog-<n>\Lot-<nnn>\<cover|title-page|interior|exterior>\` |
| קבצים שלא ניתן היה לשייך / קבצים חלקיים אחרי קריסה | `…\AVOT Studio\_unassigned\` (לא נמחקים לעולם אוטומטית) |
| קבצים בתהליך הורדה מהמצלמה | `…\AVOT Studio\.staging\` |
| הגדרות (אסימונים מוצפנים ב-DPAPI) | `%LOCALAPPDATA%\AvotCapture\settings.json` |
| מסד מקומי (תור, סטטוסים) | `%LOCALAPPDATA%\AvotCapture\captures.db` (SQLite WAL) |
| יומנים (30 יום) | `%LOCALAPPDATA%\AvotCapture\logs\agent-YYYYMMDD.log` |

## הגדרות (`settings.json`)
`StorageRoot`, `Port` (47800), `CameraMode` (`CANON`/`SIMULATOR`), `EdsdkPath`, `AutoStart`, `LocalRetentionDays` (0 = לשמור תמיד; אחרת מחיקת מקורות מקומיים *מאומתים בשרת* אחרי N ימים), `RawPlusJpegSimulation`.

הצילום נחסם כשהנפח הפנוי בכונן האחסון יורד מתחת ל-2GB; אזהרה מתחת ל-20GB (מוצגת במסך הצילום ובמסך העמדות).

## מצבי מצלמה ועיבוד
- `CameraMode`: `AUTO` (ברירת מחדל: Canon EDSDK אם מותקן, אחרת digiCamControl) | `DIGICAM` | `CANON` | `SIMULATOR` — בתפריט המגש או `--camera`. פרטים ב-[digicamcontrol.md](digicamcontrol.md). הגדרות: `DigiCamUrl`, `DigiCamExePath`, `DigiCamAutoLaunch`, `DigiCamTransfer`.
- הגדרות פרופיל הצילום (סיבוב, הסרת רקע, חיתוך …) באות מהדפדפן עם כל בקשת צילום (`processing`), נשמרות ב-`captures.db` עם הצילום ונשלחות לשרת ברישום — ה-Agent אינו מעבד תמונות. העיבוד בשרת: [green-screen-processing.md](green-screen-processing.md).

## עדכונים וגרסאות
- גרסת Agent וגרסת API נשלחות בכל heartbeat ומוצגות במסך העמדות. השרת מסרב לצימוד מגרסת API שונה.
- עדכון: הרצת קובץ התקנה חדש מעל הקיים (אותו AppId) — הנתונים, התור והתמונות נשמרים. ההתקנה סוגרת את התוכנה הרצה ומציעה להפעיל אותה בסיום; צילומים שבתור ממשיכים להעלות אחרי ההפעלה.
- הפצה עתידית אוטומטית: פרסום קובץ ההתקנה החתום בדלי/שרת + בדיקת גרסה ב-heartbeat (לא מומש בשלב זה). מומלץ לחתום את קובץ ההתקנה בתעודת Code Signing לפני הפצה.

# AVOT Capture Desktop (גרסה 0.2 ואילך)

אותו מנוע (C# / .NET), עם **חלון ניהול** גרפי. סגירת החלון רק מסתירה אותו — מנוע הצילום, השמירה המקומית וההעלאה ממשיכים ברקע (מגש המערכת). הצילום עצמו נשאר באתר אבות; התוכנה אינה מסך צילום חלופי.

## התקנה (אדמין, קובץ אחד)
באתר: הגדרות ← עמדות צילום ← **הורדת תוכנת צילום**. מריצים את הקובץ; אשף ההתקנה:
1. מתקין את התוכנה (למשתמש הנוכחי, ללא הרשאות מנהל).
2. **Canon EDSDK** — מזהה חבילה מותקנת, או מאפשר לבחור פעם אחת את ה-ZIP הרשמי שהורדתם מפורטל Canon; בודק שהוא Windows x64 (כולל כותרת ה-PE), מחלץ את ה-DLL לתיקיית נתוני התוכנה (`%ProgramData%\AvotCapture\EDSDK`) ומאמת גרסה (נבדק מול **13.20.21**; אחרת אזהרה). **אין הורדה לא מורשית או עקיפת התחברות, ואין העלאת ה-SDK ל-GitHub.** החבילה אינה נדרשת מחדש בעדכון תוכנה רגיל.
3. צימוד חד־פעמי (כתובת + קוד בן 8 ספרות).
4. תיקיית אחסון + בדיקת שטח (התראה מתחת ל-20GB).
5. **בדיקת מערכת:** תוכנה · EDSDK · זיהוי EOS R7 · צימוד · כתיבה לתיקייה · חיבור **והרשאה** לשרת. צילום ניסיון מתבצע מחלון התוכנה.

אין PowerShell ואין עריכת JSON. פקודות לשימוש האשף (וגם לתמיכה): `--check [--brief]`, `--import-sdk <zip>`, `--version`, `--pair <url> <code> [name]`.

## חלון הניהול
דגם המצלמה · USB · EDSDK · חיבור לשרת · צימוד · תמונות שממתינות להעלאה · שגיאות · מקום פנוי · גרסה · עדכון. פעולות: חיבור מחדש למצלמה, צילום ניסיון (נשמר ב-`test-shots`, לא משויך לספר ולא מועלה), פתיחת תיקיית התמונות, פתיחת האתר, הצגת שגיאות, תיקיית אחסון, בדיקת מערכת, ייבוא EDSDK, בדיקת עדכונים, הפעלה אוטומטית.

## צימוד חד־פעמי והחלפת מחשב
האסימון והסוד שמורים מוצפנים ב-DPAPI בתיקיית הנתונים. כיבוי/הדלקת מצלמה, ניתוק USB, הפעלה מחדש של Windows או של התוכנה — **אינם דורשים צימוד חדש**; הסוכן מתחבר מחדש למצלמה אוטומטית, פותח session חדש ומשחזר Live View, והדפדפן מחדש את הרשאת השליטה הזמנית בעצמו. מעבר למחשב חדש: מתקינים בו, ובשורת העמדה באתר לוחצים ״צימוד מחדש״ — האסימון הישן מבוטל מיד והמחשב הישן מאבד שליטה. שני עובדים לא שולטים באותה מצלמה (lease אחד).

## עדכונים אוטומטיים
כל 6 שעות (ובהפעלה) התוכנה שואלת את השרת (`GET /api/agent/update`, מאומת בהרשאת העמדה). גרסה חדשה: הורדה ממקור **https** בלי להעביר אליו את אסימון העמדה, אימות **SHA-256** (וחתימת Authenticode אם הוצמד חותם), התקנה רק כשהעמדה **לא** מצלמת ואינה מקבלת קובץ ושום עובד לא שולט בה, גיבוי תיקיית התוכנה הקודמת, התקנה שקטה והפעלה מחדש. הגרסה החדשה צריכה להוכיח את עצמה: אחרי שתי הפעלות כושלות — **שחזור אוטומטי** לגרסה הקודמת. ההגדרות, הצימוד, המסד המקומי והתמונות נמצאים מחוץ לתיקיית ההתקנה ואינם נמחקים; צילומים שלא הועלו נשארים. עדכוני Canon EDSDK אינם חלק מכך (רישוי Canon).

פרסום גרסה: `.\build-installer.ps1 -Version 0.2.0 -Publish -DownloadUrl https://<אחסון>/AvotCaptureDesktop-Setup-0.2.0.exe [-SignerThumbprint <SHA1>]` — מייצר את הקובץ והמניפסט; מעלים את הקובץ לכתובת, ומגדירים בשרת `AGENT_RELEASE_MANIFEST`.

## מחיקות מהשרת
עמדה מצומדת מוחקת את העותקים המקומיים של ספרים שנמחקו לצמיתות באתר ([deletion.md](deletion.md)); `SyncDeletions` מכבה זאת.

> **סטטוס:** כל הקוד שלמעלה נכתב ללא .NET SDK זמין — לא קומפל ולא נבדק (חוץ מבדיקות Core ב-`DesktopFeatureTests`). לפני שחרור: `dotnet build`, `dotnet test`, `build-installer.ps1`, ובדיקה בחומרה.
