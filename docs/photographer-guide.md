# מדריך עבודה לצלם

## לפני שמתחילים
1. מדליקים את המצלמה (או מחברים את הטלפון כמצלמת רשת). ב-Canon: סמל ״A״ ירוק במגש המערכת = מצלמה מחוברת.
2. נכנסים ל-AVOT Studio ← **לוח עבודה**. אם עבדתם קודם, יופיע ״המשך מהנקודה האחרונה״ — לחיצה על **המשך צילום** מחזירה לאותו ספר ולאותה קטגוריה.
3. אחרת: **קטלוגים** ← בחירת קטלוג ← בשורת הספר **צילום**. אפשר גם לסרוק את תווית ה-QR של הספר בטלפון, או בסורק USB לשדה החיפוש שבראש המסך.

## מסך הצילום
- **במרכז:** תצוגה חיה. כלי עזר (רשת, קווי מרכז, הדגשת פוקוס, הגדלה 2×/4×, סיבוב תצוגה) הם תצוגה בלבד — אינם נשמרים בקובץ.
- **בצד:** מספר הפריט ושם הספר, ארבע הקטגוריות עם מונה, הגדרות המצלמה (מוצגות רק הגדרות שהמצלמה תומכת בהן).
- **למטה:** רצועת הצילומים האחרונים. לכל צילום מספר רץ ומצב:
  - 🟫 דיסק — **נשמר מקומית** (בטוח במחשב, עוד לא בענן)
  - ⏫ — ממתין להעלאה / מעלה
  - ✓ ירוק — **נשמר בענן ואומת**
  - ✕ אדום — הצילום נכשל ולא נשמר (צלמו שוב)
  - ⚠ — שמור מקומית אבל ההעלאה נתקלת בבעיה (ממשיך לנסות; ראו טיפול בתקלות)

## צילום
| פעולה | מקש |
|---|---|
| צילום | **רווח** · כפתור העיגול · דוושת USB (אם הוגדרה) · כפתור המצלמה (Canon) |
| כריכה / שער / פנים / חוץ | 1 / 2 / 3 / 4 |
| פריט הבא / קודם | N / P |
| רשת · הגדלה · סיבוב תצוגה | G · Z · R |
| מסך מלא · הסתרת פאנלים | F · H |
| סגירת תמונה מוגדלת · ניווט | Esc · חיצים |

אין צורך לחכות להעלאה כדי לצלם שוב. אפשר להחליף קטגוריה מיד אחרי לחיצה — הצילום יישמר בקטגוריה שבה נלחץ.

## סדר עבודה רציף (100 ספרים על השולחן)
1. מסמנים ״צילום רציף לפי פריטים״ בפאנל.
2. לכל ספר: כריכה (1) ← שער (2) ← פנים (3) ← חוץ (4) לפי הצורך.
3. **סיום פריט** ← מאשרים ← המערכת עוברת לספר הבא, המצלמה נשארת מחוברת.
4. ספר שלא צריך בו קטגוריה מסוימת: במסך הספר לוחצים על סמל ⊘ בקטגוריה (״לא נדרש״).

## תיקונים
- **צילום מחדש:** ריחוף על הצילום ברצועה ← ↺. הצילום הבא יוצע כתחליף; הישן נשאר עד שתאשרו להעביר אותו לסל המחזור.
- **מחיקה:** 🗑 — לסל המחזור (שחזור אפשרי 30 יום). ניתן לבטל מיד מההודעה.
- **תמונה ראשית:** ☆ ברצועה או בגלריה.
- **סידור, סיבוב, חיתוך תצוגה, העברה בין קטגוריות או ספרים, השוואה בין שתי תמונות:** במסך הספר (התמונות מוצגות בו ישירות, לפי לשוניות קטגוריה).

## סוף יום
- ודאו שבראש המסך אין ״ממתינות להעלאה״. אם יש — השאירו את הדפדפן/העמדה פתוחים עד שיתאפס. הצילומים לא יאבדו גם אם תסגרו; הם יעלו בפתיחה הבאה.
